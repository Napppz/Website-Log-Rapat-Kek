Standarisasi Nama 14 Entitas di Neon PostgreSQL (3NF)

Daftar penamaan Primary Key dan Foreign Key 100% konsisten dalam 5 Klaster Fungsional untuk laporan Tugas Akhir.

14 Entitas Aktif
Klaster Nama Tabel Fisik Primary Key (PK) Foreign Key Masuk (FK) Kardinalitas & Deskripsi
1. Organisasi & Akun biro id_biro - Master unit kerja eselon tingkat biro (IKK, BPPK, PKKEK, HSDMO, UK).
tim_biro id_tim id_biro → biro Unit kerja teknis pelaksana rapat dinas (Tim Investasi, Kerja Sama, Komunikasi).
pengguna id_pengguna
id_biro → biro
id_tim → tim_biro (Null)
 Akun aparatur aparatur sipil negara, pimpinan sidang, notulis, dan PIC penugasan.
2. Pelaksanaan Rapat penomoran_rapat_biro id_penomoran id_biro → biro (1:1 UK) Generator nomor registrasi surat urut otomatis per biro (atomic sequence counter).
rapat id_rapat
id_biro → biro
id_tim → tim_biro
id_pengguna → pengguna
id_notulis → pengguna
id_rapat_sebelumnya → rapat
 Agenda rapat dinas KEK dengan nomor unik resmi (nomor_rapat, cth: INV-015).
rapat_biro (id_rapat, id_biro) PK Composite FK (M:N) Tabel perantara (junction) untuk rapat gabungan lintas biro di Sekretariat Dewan Nasional.
peserta_rapat id_peserta
id_rapat → rapat
id_pengguna → pengguna
 Daftar kehadiran peserta undangan rapat beserta status presensi (INVITED, PRESENT).
lampiran_rapat id_lampiran id_rapat → rapat Dokumen materi paparan, undangan disposisi, dan berkas digital pendukung rapat.
3. Notulensi & Risalah notulen_rapat id_notulen id_rapat → rapat (1:1 UK) Naskah risalah resmi: butir agenda, hasil pembahasan, kesepakatan keputusan, & kesimpulan.
komentar_notulen id_komentar
id_rapat → rapat
id_pengguna → pengguna
id_induk → komentar (Unary)
 Kolaborasi review draft notula dinas dengan fitur balasan utas (id_induk).
riwayat_notulen id_riwayat
id_rapat → rapat
id_pengguna → pengguna
 Audit trail kepemerintahan untuk melacak versi, perubahan kolom, nilai lama, dan nilai baru.
4. Tindak Lanjut tindak_lanjut id_tindak_lanjut
id_rapat → rapat
id_biro → biro
id_tim → tim_biro (Null)
id_pengguna → pengguna (Null)
 Butir resolusi arahan rapat, tenggat waktu (tenggat_waktu), prioritas, dan PIC penugasan.
riwayat_tindak_lanjut id_riwayat
id_tindak_lanjut → tindak_lanjut
id_pengguna → pengguna
 Catatan log berkala perkembangan dan pembaruan status tugas tindak lanjut.
5. Komunikasi notifikasi id_notifikasi id_pengguna → pengguna Pemberitahuan real-time untuk undangan rapat baru, revisi notula, dan peringatan tenggat waktu tugas.

SD-01: Penjadwalan Rapat Dinas Baru & Penomoran Otomatis

Interaksi Admin Biro/Tim memicu pembuatan rapat, auto-increment sequence, dan blasting notifikasi.

sequenceDiagram
    autonumber
    actor Admin as 👤 Admin Biro/Tim
    participant UI as 💻 BuatRapatPage (UI)
    participant Action as ⚙️ meetingAction (Server)
    participant DB_Seq as 🗄️ penomoran_rapat_biro
    participant DB_Mtg as 🗄️ rapat
    participant DB_Part as 🗄️ peserta_rapat
    participant DB_Notif as 🗄️ notifikasi

    Admin->>UI: Buka form 'Buat Rapat' & pilih Biro/Tim
    UI->>Action: getNextMeetingNumber(id_biro)
    Action->>DB_Seq: SELECT nomor_terakhir FOR UPDATE
    DB_Seq-->>Action: nomor_terakhir = 14
    Action-->>UI: nomor_rapat = "IKK-015"
    
    Admin->>UI: Input Judul, Tanggal, Jam, Lokasi, Pimpinan, Peserta & Lampiran
    Admin->>UI: Klik 'Jadwalkan Rapat'
    UI->>Action: createMeeting(dataRapat, listPeserta)
    Action->>DB_Mtg: INSERT INTO rapat VALUES (...)
    Action->>DB_Seq: UPDATE penomoran_rapat_biro SET nomor_terakhir = 15
    Action->>DB_Part: INSERT INTO peserta_rapat VALUES (...)
    Action->>DB_Notif: INSERT INTO notifikasi VALUES (...)
    Action-->>UI: Return { success: true, id_rapat: "MTG-015" }
    UI-->>Admin: Tampilkan Toast Sukses & Alihkan ke Detail Rapat

Logical Record Structure (LRS) 14 Entitas

Blok rekod logis hasil transformasi ERD ke LRS siap disalin ke Bab III Skripsi / Laporan Tugas Akhir.

1. biro (*id_biro <PK>, kode_biro <UK>, nama_biro, nama_singkat, deskripsi, status_aktif)
2. tim_biro (*id_tim <PK>, **id_biro <FK>, kode_tim, nama_tim, deskripsi_tim, status_aktif)
3. pengguna (*id_pengguna <PK>, **id_biro <FK>, **id_tim <FK>, nama_lengkap, email <UK>, peran, status_aktif)
4. penomoran_rapat_biro (*id_penomoran <PK>, **id_biro <FK, UK>, nomor_terakhir)
5. rapat (*id_rapat <PK>, nomor_rapat <UK>, judul_rapat, **id_biro <FK>, **id_tim <FK>, **id_pengguna <FK>, **id_notulis <FK>, **id_rapat_sebelumnya <FK>, tanggal_rapat, status_rapat)
6. rapat_biro (*id_rapat <PK, FK>, *id_biro <PK, FK>)
7. peserta_rapat (*id_peserta <PK>, **id_rapat <FK>, **id_pengguna <FK>, status_kehadiran)
