c. Spesifikasi Basis Data (Data Dictionary)

Struktur teknis 8 tabel inti basis data PostgreSQL (Neon DB) dengan penegasan fungsi Primary Key (PK) dan Foreign Key (FK) sesuai standar Laporan PKL Universitas BSI.

Tabel III.1. Spesifikasi Tabel Pengguna (pengguna) 10 Fields
No Nama Field Tipe Data Keterangan
1 id_pengguna PK 🔑 Varchar (UUID) Primary Key
2nama_lengkapVarcharNama lengkap aparatur / pegawai
3emailVarcharEmail dinas resmi (Unique)
4kata_sandiVarcharPassword terenkripsi (Bcrypt hash)
5peranEnumSUPER_ADMIN, ADMIN, PIMPINAN, STAFF
6 id_biro FK 🔗 Varchar (UUID) Foreign Key (Relasi ke tabel biro)
7 id_tim FK 🔗 Varchar (UUID) Foreign Key (Relasi ke tabel tim_biro, opsional)
8status_aktifBooleanStatus aktif akun (Default: true)
9dibuat_padaTimestampWaktu akun didaftarkan
10diperbarui_padaTimestampWaktu terakhir pembaruan profil
Tabel III.2. Spesifikasi Tabel Biro (biro) 8 Fields
No Nama Field Tipe Data Keterangan
1 id_biro PK 🔑 Varchar (UUID) Primary Key
2kode_biroVarcharKode singkatan unik biro (Unique)
3nama_biroVarcharNama lengkap biro pemrakarsa
4nama_singkatVarcharNomenklatur singkatan biro
5deskripsiTextUraian fungsi pokok biro
6status_aktifBooleanStatus aktif operasional biro
7dibuat_padaTimestampWaktu data biro dibuat
8diperbarui_padaTimestampWaktu terakhir data diperbarui

No Nama Field Tipe Data Keterangan

4nama_timVarcharNama kelompok kerja / tim
5deskripsi_timTextUraian bidang penugasan tim
6status_aktifBooleanStatus keaktifan tim kerja
7dibuat_padaTimestampWaktu tim dibentuk
8diperbarui_padaTimestampWaktu pembaruan data tim

No Nama Field Tipe Data Keterangan
1 id_rapat PK 🔑 Varchar (UUID) Primary Key

6tanggal_rapatTimestampTanggal pelaksanaan rapat dinas

12status_rapatEnumDRAFT, REVIEW, APPROVED, FINAL

14pic_rapatVarcharNama penanggung jawab teknis rapat
15status_progresVarcharStatus tahapan progres rapat
16dibuat_padaTimestampWaktu agenda rapat dibuat
17diperbarui_padaTimestampWaktu pembaruan data rapat

No Nama Field Tipe Data Keterangan

No Nama Field Tipe Data Keterangan
